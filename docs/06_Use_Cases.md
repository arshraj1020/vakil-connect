# 6. Use Cases

## 6.1 Overview

Use cases describe the interactions between different stakeholders and the VakilConnect platform. They define the primary functionalities that the system must support.

---

# Client Use Cases

| Use Case ID | Use Case | Description |
|--------------|----------|-------------|
| UC-01 | Register | Create a new client account |
| UC-02 | Login | Authenticate into the platform |
| UC-03 | Manage Profile | Update personal information |
| UC-04 | Search Lawyers | Search lawyers using keywords |
| UC-05 | Filter Lawyers | Filter by specialization, location, language, fee, and rating |
| UC-06 | View Lawyer Profile | View detailed lawyer information |
| UC-07 | Book Appointment | Schedule a consultation with a lawyer |
| UC-08 | Cancel Appointment | Cancel an existing booking |
| UC-09 | View Appointment History | View previous and upcoming consultations |
| UC-10 | Upload Documents | Upload legal documents for consultation |
| UC-11 | Download Documents | Download uploaded legal documents |
| UC-12 | Submit Review | Rate and review a lawyer |
| UC-13 | Chat with AI Assistant | Ask legal questions and receive AI guidance |
